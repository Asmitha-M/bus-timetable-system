# Integrated Bus Time Table System

SDLC project demonstrating Jira, Confluence, and GitHub usage.

## Project Modules
- View Bus Routes
- View Bus Schedules
- Admin Add/Update Schedule

## Folder Structure
backend/   - Backend placeholder code  
frontend/  - UI pages (routes, schedule)  
database/  - SQL schema  
docs/      - API list documentation  

## Tools Used
- Jira: Task and workflow management
- Confluence: Documentation
- GitHub: Version control

## Jira Integration
Commits reference Jira tasks such as KAN-5, KAN-6, KAN-9.
